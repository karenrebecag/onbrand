# layout

- `layout-cluster` · Cluster · [anida: children] · Fila que envuelve, para acciones, logos o etiquetas.
- `layout-grid` · Grid · [anida: children] · Grilla responsive por columnas (base, md, lg).
- `layout-image` · Image · [hoja] · Imagen con marco por token; data-alt es el prompt del paso de imagen.
- `layout-section` · Section · [anida: backdrop,children] · Contenedor de cada sección: ancla, rol, ancho, superficie y padding del contrato de página.
- `layout-split` · Split · [anida: children] · Dos columnas en escritorio (1:1, 1:2, 2:1), una en móvil.
- `layout-stack` · Stack · [anida: children] · Apila hijos en columna con un espacio de la escala.
- `layout-text` · Text · [anida: children] · Texto con rol tipográfico (display, title, subtitle, body, caption).
